# 📚 Sistema de Gestió de Biblioteca (Biblioteca Project)

Aplicació de gestió de biblioteca desenvolupada per controlar el préstec de llibres, el registre d'usuaris i l'administració de catàlegs de manera eficient.

## 🚀 Tecnologies i Eines
* **Llenguatge / Entorn:** Java / PHP (segons la tecnologia del teu projecte)
* **Base de Dades:** MySQL
* **Control de Versions:** Git & GitHub

## 📂 Estructura del Projecte
El codi font està organitzat de manera modular:
BIBLIOTECA/
│
├── src/ (o arxius principals del projecte)
│   ├── Llibre.java / Models
│   ├── Usuari.java
│   └── Prestec.java
│
└── README.md


## 🛠️ Característiques Principals
* Gestió completa de lres (alta, baixa, consulta i actualització).
* Control de socis o usuaris de la biblioteca.
* Sistema de préstecs i devolucions amb control d'estats.
